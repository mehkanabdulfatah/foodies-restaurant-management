# 🍔 Foodies – Restaurant Management System

A modern and responsive restaurant food ordering website built using React.

## 📌 Project Overview

Foodies Restaurant Management System is a web-based application designed to make online food ordering simple and convenient.

Customers can explore food items, add their favorite meals to the shopping cart, manage quantities, and enter their delivery details.

## 🎯 Project Objectives

- Create an attractive restaurant homepage.
- Display available food items and prices.
- Allow customers to add food to their cart.
- Manage food quantities.
- Calculate the total order price.
- Provide a checkout form for customer details.
- Develop a user-friendly and responsive interface.

## ✨ Features

- Responsive restaurant homepage
- Navigation bar
- Food menu section
- Add to Cart functionality
- Increase and decrease food quantity
- Remove items from cart
- Automatic price calculation
- Customer checkout form
- Order confirmation message

## 🚀 Installation and Setup

### Prerequisites

- Node.js
- npm
- Git
- Visual Studio Code

### Step 1: Clone the repository

```bash
git clone https://github.com/MehkanSarfraz/foodies-restaurant-management.git
```

### Step 2: Open the project

```bash
cd foodies-restaurant-management
```

### Step 3: Navigate to frontend

```bash
cd frontend
```

### Step 4: Install dependencies

```bash
npm install
```

### Step 5: Run the application

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 🛒 How to Use

1. Open the Foodies homepage.
2. Browse the available food items.
3. Click Add to Cart.
4. Increase or decrease item quantities.
5. Remove unwanted items.
6. Check the total price.
7. Enter customer details in the checkout form.
8. Click Place Order to see the confirmation message.
